사용 방법

  1. 펜이나 형광펜 도구를 선택하세요.
  2. 손가락 한 개로 문서를 끌어 이동하세요. 이때 선이 그려지면 실패입니다.
  3. S펜으로 선을 그어 보세요. 손가락과 달리 필기가 되어야 합니다.
  4. 손가락 두 개로 확대·축소한 뒤 다시 S펜으로 필기해 보세요.
  5. 서브노트·교재·이미지·첨부 PDF 네 탭에서도 각각 확인하세요.

동작 원칙

손가락: 언제나 이동·확대

S펜: 선택한 주석 도구

PC 마우스는 테스트 편의를 위해 선택한 도구로 그릴 수 있습니다. 마우스는 손가락과 구분됩니다.

이 페이지는 실제 학습노트 주석 코드 수정 전의 동작 검증용 시제품입니다. 실기기 확인 후 운영 코드에 동일한 입력 규칙을 적용합니다.
