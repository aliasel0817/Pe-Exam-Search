# 오늘의 학습 통합 (검수용 작업 브랜치)

- 브랜치: feature/study-planner-20261023
- 운영 main, LIVE MASTER, 학습정보 시트 미수정
- 학습 현황에 '오늘의 학습 · 계획' 탭을 추가; 기존 '오늘의 학습'은 '오늘 학습한 기록'으로 별도 보존
- 일자 / 회독 / 그룹 / 통합ID별 예정 토픽 조회
- 통합ID 클릭시 기존 메인뷰 학습 내용으로 이동
- 선택한 토픽을 메인뷰에서 기억함/다시보기 클릭하면 계획별 상태에 기록
- 계획 JSON 추가 등록(동일 ID 덮어쓰기 차단)
- 계획 진도 저장소: 별도 IndexedDB pe-study-planner-v1; 기존 학습정보 및 MASTER 비수정
- 진도 백업/복원(JSON) 기능

## 데이터 등록

이 브랜치에는 100일 전체 일정 19,060건을 정적 JSON으로 자동 탑재합니다.
기본 계획은 최초 실행 시 별도 IndexedDB에 저장되고 이후 로컬 진도와 함께 유지됩니다.
새 학습계획은 학습 > 오늘의 학습 · 계획 > 계획 등록·관리에서 JSON으로 추가할 수 있습니다.
같은 ID의 계획은 덮어쓰지 않으며 원본 MASTER에는 영향을 주지 않습니다.
기기 간 자동 진도 동기화, PDF 직접 가져오기, 앱 화면에서 일정 편집은 후속 단계입니다.

## 검수 전제

1. 운영에 병합하지 않은 검수 전용 브랜치입니다.
2. 정적 구문 검사 및 기존 학습 기록 보존 검사를 수행합니다.
3. 19,060건 데이터 실제 가져오기/복원/PC·모바일 QA가 완료되기 전 운영 배포하지 않습니다.
4. 진도 동기화는 아직 해당 기기 로컬에만 적용됩니다.

## 페이지 분할 개선 (2026-10-23)

- 오늘의 학습·계획 목록은 기본 20개씩 표시하며 페이지당 10·20·30·50개를 선택할 수 있습니다.
- 이전·다음, 페이지 번호 직접 입력과 현재 표시 범위/전체 검색 결과 수를 보여줍니다.
- 날짜·계획·검색·상태 필터·표시 개수 변경 시 1페이지로 이동하고, 필터 결과가 줄면 마지막 유효 페이지로 보정합니다.
- 그룹 제목의 수량은 현재 페이지 수량과 필터 적용 후 그룹 전체 수량을 구분합니다.
- 선택한 표시 개수만 로컬에 저장하며, 기존 MASTER/학습정보/진도 DB 스키마는 변경하지 않습니다.
- Chromium 자동 테스트: 137건을 20개씩 7페이지, 마지막 17개, 10개/50개 전환, 검색/완료 필터, 날짜 초기화, 기억함·계획 진도, 오프라인 재진입, 모바일·태블릿·PC 너비 확인.

## 화면 사용성 개선 (2026-10-23: 그룹/가져오기/백업)

- 그룹 필터: `학습 그룹` 콤보박스에 선택 날짜의 실제 배정 그룹만 `전체 그룹` + 그룹코드·그룹명·전체 수량으로 표시합니다.
- 그룹 선택은 해당 그룹의 토픽만 검색/진도 필터한 뒤 페이지를 나눕니다. 날짜·계획 변경 시 그룹은 전체로 복귀합니다.
- 최초 페이지당 표시 개수는 **10개**입니다. 기존 v1 페이지 크기 저장값과 분리한 `peStudyPlanner.pageSize.v2`로 최초 10개를 보장하고 이후 사용자가 변경한 값을 유지합니다.
- 통계 안내 문자열 글꼴은 아래의 로컬 진도 안내와 같은 `0.8rem` (기본 12.8px)로 줄입니다.
- `계획 추가 · 진도 관리` 버튼은 새 학습계획 등록, 회독 진도 백업과 복원 설명을 목록 위에 펼칩니다.

### 새 학습계획 등록 파일

1. `CSV 작성 예제 다운로드`를 누르면 Excel에서 편집 가능한 UTF-8 BOM 기반 CSV 파일을 받습니다.
2. 첫 행 열 이름: `planId,planName,date,round,groupCode,groupName,topicId`.
3. 한 행에 계획·날짜·회독·그룹·통합ID를 지정합니다. planId와 planName은 같은 계획의 모든 행에서 동일해야 합니다.
4. 예제의 유효한 통합ID를 필요에 맞게 바꿔 입력하고 CSV UTF-8로 저장합니다.
5. `학습계획 파일 선택 — 새 계획 등록용` 입력란에서 CSV 또는 JSON을 선택하면 형식·중복 날짜/토픽·MASTER 매칭을 검사하고 새 계획으로 등록합니다.
6. 기존 계획 변경은 **새 planId(예: my-review-v2)**를 지정하여 새 버전을 등록합니다. 동일 ID의 기존 계획과 진도는 덮어쓰지 않습니다. PDF와 XLSX를 직접 업로드하는 기능은 아직 없습니다.

JSON 예제 다운로드는 다음 데이터 형태를 사용합니다. `groups`는 코드→그룹명 매핑입니다.

```json
{
  "id": "my-review-2026-v1",
  "name": "나만의 복습 학습계획 (예제)",
  "groups": {"A": "SW 개발", "B": "보안"},
  "days": [
    {"date": "2026-10-24", "round": 1, "ids": ["T0692", "T3125"], "groups": ["A", "B"]},
    {"date": "2026-10-25", "round": 2, "ids": ["T0692"], "groups": ["A"]}
  ]
}
```

### 진도 백업과 복원

- 진도 백업은 **이 브라우저 IndexedDB 내 학습계획별 완료(기억함)/다시보기 진행기록만** `study-plan-progress-backup.json`으로 내려받습니다. 기존 Google Sheets `학습정보`나 MASTER 원문을 백업하지 않습니다.
- 진도 복원은 위 파일을 선택하고 형식·키·날짜·등록 계획 존재 여부를 검증합니다. 기존 동일 키가 있을 때 명시적 확인 후 일괄 기록하며, 확인 취소 시 기존 기록을 보존합니다.
- 기기간 자동 동기화는 **아직 구현되지 않았으므로** 기기 이동 전 백업 파일 보관 및 대상 기기에서 계획 등록 후 진도 복원이 필요합니다.
- 검증: 그룹 G24(34개/기본 10개씩 4페이지), CSV/JSON 다운로드와 등록, 중복 ID 거부, 잘못된 ID 거부, 진도 다운로드/복원/덮어쓰기 확인, 390·820·1280px 화면, 오프라인, 기존 학습기능 회귀 테스트를 통과했습니다.
