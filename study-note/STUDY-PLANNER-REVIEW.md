# 오늘의 학습 통합 (검수용 작업 브랜치)

- 브랜치: feature/study-planner-20261023
- 운영 main, LIVE MASTER, 학습정보 시트 미수정
- 학습 현황에 '오늘의 학습 · 계획' 탭을 추가; 기존 '오늘의 학습'은 '오늘 학습한 기록'으로 별도 보존
- 일자 / 회독 / 그룹 / 통합ID별 예정 토픽 조회
- 통합ID 클릭시 기존 메인뷰 학습 내용으로 이동
- 선택한 토픽을 메인뷰에서 기억함/다시보기 클릭하면 계획별 상태에 기록
- 계획 JSON 추가 등록(동일 ID 덮어쓰기 차단)
- 계획 진도 저장소: 별도 IndexedDB pe-study-planner-v1; 기존 학습정보 및 MASTER 비수정
- 진도 백업/복원(JSON) 기능

## 데이터 등록

이 브랜치에는 100일 전체 일정 19,060건을 정적 JSON으로 자동 탑재합니다.
기본 계획은 최초 실행 시 별도 IndexedDB에 저장되고 이후 로컬 진도와 함께 유지됩니다.
새 학습계획은 학습 > 오늘의 학습 · 계획 > 계획 등록·관리에서 JSON으로 추가할 수 있습니다.
같은 ID의 계획은 덮어쓰지 않으며 원본 MASTER에는 영향을 주지 않습니다.
기기 간 자동 진도 동기화, PDF 직접 가져오기, 앱 화면에서 일정 편집은 후속 단계입니다.

## 검수 전제

1. 운영에 병합하지 않은 검수 전용 브랜치입니다.
2. 정적 구문 검사 및 기존 학습 기록 보존 검사를 수행합니다.
3. 19,060건 데이터 실제 가져오기/복원/PC·모바일 QA가 완료되기 전 운영 배포하지 않습니다.
4. 진도 동기화는 아직 해당 기기 로컬에만 적용됩니다.
