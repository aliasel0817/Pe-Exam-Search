## 3. 기존 대비 삭제 여부 및 통합 규칙

- **2026-10-06 Y 백업에도 T2714의 Session Presentation, T2715의 Network DataLink 묶음이 이미 존재**. 10월 11일 이후 LIVE Y 변경 0. **최근 가독성 작업이 7개를 6개로 삭제했다는 주장 불가**.
- 7개 계층 모두 현재 LIVE X에서 구분되므로 *토픽 전체 핵심지식의 완전 소실*도 아님. 이는 **Y열 구성요소 7개 분리 역할 설명의 명료성·완전성 후보**.
- ISO/IEC 7498-1 또는 ITU-T X.200의 OSI 참조모델 구조에서 7계층으로 나뉘는 체계를 학습하기 위해 원천의 7단을 각각 보존하는 것이 목적. 용어를 줄이기 위해 합치거나 인접 계층 사이의 서비스·프로토콜 관계를 임의로 단순화하지 않음.
- 세션, 표현, 네트워크, 데이터링크 계층의 기존 설명을 반드시 유지하면서 **Y의 각 구성요소가 분리되도록 하는 최소 보강안** 작성 가능. 문구 수정·LIVE 반영은 **사용자 승인 전 보류**.
- NW 전체 401 학습대상 중 우선 위험 후보 **2건의 연결 PDF 시각 1차 검수**이며, NW 전수 401건의 기술 정확성 검수 완료가 아님.
