## M7 실제 수정

M6 scroll coalescer는 Worker abort 및 페이지 serial 검사를 이미 사용하지만, 페이지 전환/모달 닫기 직전에 예약된 JavaScript 타일 콜백을 제거하는 명시적 경로가 없었다. **이전 뷰어의 대기 콜백이 닫힌 문서에서 다시 스케줄을 시도하는 경로를 보강**했다.

1. `m6/m6-interaction-policy.mjs`: `createM6ScrollCoalescer().cancel()` 추가. 예약 timer·pending 함수·최초 시각 해제, 대기열은 다음 페이지에서 재사용.
2. `m6/m6-runtime.js`: `__M6_PERF__.cancelTile(kind)` 내부 API 추가(기존 로컬 private gate 아래).
3. `m5/m5-attachment-ui.js`: `m5StopPageRendering()` 초기에 attachment 대기열 및 zoom-anchor 취소.
4. `study-note/study-note.html`: `resetReferencePdfHighQualityRenderer()` 초기에 reference 대기열 및 zoom-anchor 취소.
5. `m7/tests/m7.test.mjs`: 신규 4가지 회귀검사. 기존 HTML 원문과의 diff로 주석·보안·API 보존 테스트.
6. `.github/workflows/mupdf-m7-final-stabilization.yml`: read-only, non-deploy M1~M7 Actions.

변경 범위에 데이터 마이그레이션, 필기 저장 포맷 수정, 서버 함수 교체, 운영 기능 활성화 없음. 신규 취소 호출도 M6 private opt-in 환경에서만 활성화.
