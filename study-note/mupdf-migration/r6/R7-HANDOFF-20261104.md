## 2. R7 최우선 개발 과제 (완료 조건 및 증거 확보)

1. **적법한 완전 대응 소스:** 사용자 소유 코드, MuPDF Worker/adapter, 결합 Apps Script 백엔드의 실제 연결 범위·제3자 권리를 확인하고, 포함된 PDF.js / pdf-lib / SheetJS / MuPDF 18 모듈/폰트/CMap/ICC 저작권 고지를 완성한다. AGPL 기술적 주장과 최종 법률 판단을 구분한다.
2. **서버 소스 최신성:** 운영 Apps Script 배포 ID/실제 최신 버전/HEAD를 허용된 읽기 전용 경로로 확인한다. R5 공개 Code.js v21 snapshot과 비교해 달라졌다면 민감정보 분리 및 검토된 변경분만 독립 PR 후보로 준비한다.
3. **출시 바이너리 연결:** 이미 성공한 R5 Emsdk 4.0.8 C→WASM 해시 증거를 원본 SHA/18 submodules/Node22 npm lock/build script/정확한 배포 JS/WASM 구성 파일과 문서로 연결한다. 실제 공개 대상 소스가 사용자에게 수정·재빌드 가능해야 한다. 중복 WASM 전체 빌드 금지.
4. **불변 source offer:** 정확한 최종 릴리스 커밋 또는 태그로 접근 가능한 AGPL 전문, 소스, third-party NOTICE, 변경내역, 설치·빌드 절차를 제공하고 이 URL을 테스트한다. 단순 공개 후보 브랜치를 정식 offer라고 주장하지 않는다.
5. **운영 기능 연결:** R6 출시 플래그가 확인된 경우에만 실제 서브노트·교재·첨부 PDF 원본 자동 MuPDF 고화질과 PDF.js fallback, 주석/수식/펜·형광펜·S Pen·핀치·페이지 이동을 사용한다. 원본 PDF signed GET과 mediaContent 권한/캐시 정책 유지. 장애 시 사용자 원본을 수정하지 않고 보수적 fallback 적용.
