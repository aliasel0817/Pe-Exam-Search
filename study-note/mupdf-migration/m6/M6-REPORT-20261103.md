## 4. Windows 실제 Chrome 156 — M6 합성 데이터 결과

- Local-only gate PASS. 실제 앱 HTML을 ephemeral 127.0.0.1 서버로 제공. 모든 외부 요청 차단, 기존 mediaContent GET 5회는 synthetic PDF 응답으로 가로채 처리; 운영 Apps Script·Drive 접촉 및 mutation 각 0.
- 첨부 PDF A 2페이지, PDF B 1페이지, MuPDF Worker, 회전/CropBox, 주석 페이지별 키, PDF.js 6.5.438 복구, 문서 닫기/Worker 자원 정리, 빠른 2→1→2 페이지 race PASS.
- 기존 필기 schema 3/normalized-0-1, synthetic 메모리 내 필기 1개 페이지 재방문 후 복원 PASS. 실제 클라우드 영속 저장 검증 아님.
- S Pen PointerEvent 모의: contact 0/pressure 0 hover형 pointerdown은 스트로크 미생성, pressed pen pressure 0.35→0.78 sample 2개 정상 기록, palm Touch wide 58×32px는 추가 stroke 미생성. 실물 S Pen 검증 아님.
- 핀치 focal 유지: 선택한 합성 테스트 위치에서 확대 전후 anchor 오차 0.47045 CSS px.
- scroll 이벤트 burst 65개 중 64개 통합, 타일 scheduling 실행 1회. **전체 Worker render가 1회라는 뜻 아님**.
- M5 zoom 4x: preview 12,338,352 bytes, tile 18,993,320 bytes, pixel density base 0.343 / detail 2.001 px per CSS px.
- M5 zoom 8x: preview 12,338,352 bytes, tile 18,982,048 bytes, density base 0.172 / detail 2.001.
- M5 zoom 10x: preview 12,338,352 bytes, tile 19,000,060 bytes, density base 0.137 / detail 2.001.
- base preview 예산 최대 12MiB, detail tile 최대 32MiB 준수. 함수 단계별 raster time 약 12~26ms(합성 PDF·단일 PC의 순간 관측, 일반 환경 전체 UI 지연 시간 아님).
- M4 교재 8x: preview 12,338,352 bytes, tile 14,592,000 bytes, 페이지 주석 schema 3, Worker MuPDF.
- Android tablet 유사 Chromium touch: 16MiB 제한 profile, 터치 pinch 1.8배, viewport resize 및 재배치 1회, 기존 문서 유지.

- 브라우저 page/console runtime 오류: 0.

## 5. 보존 및 위험 관리

- Git: 신규 M6 브랜치+Draft PR만 사용, main/integration 및 다른 채팅의 폴더·프로세스 무변경.
- 서버: Google Apps Script 현재 코드를 수정하지 않았고 Script Properties/인증 비밀/운영 배포를 건드리지 않음.
- 데이터: LIVE MASTER/Drive PDF·이미지·첨부·실사용 주석에 테스트 쓰기 금지, 실제 데이터 접근 없음. 합성 브라우저 데이터만 사용.
- 기존 M3 MuPDF 및 PDF.js safe fallback 재사용. 기존 운영 PDF.js 3.11.174 CVE-2024-4367은 운영 미변경으로 남음.
- 보안 테스트와 GitHub CI에서 MuPDF JS/WASM 공개 배포 차단 게이트 유지.
- AGPL-3.0-or-later 대응 소스·Apps Script 결합 관계·WASM 재빌드 요건은 법적으로 확정하지 않았으므로 **공개 NO-GO**.

## 6. 아직 검증하지 못한 M7 수용검사

1. 실제 ACTIVE 신뢰기기의 서브노트/교재 signed GET, 첨부 mediaContent GET 원본 PDF 조회.
2. 실제 사용자가 이미 저장한 필기의 Cloud 업로드·복원 (격리 사본과 승인 없이는 운영 데이터 테스트 쓰기 금지).
3. Galaxy Tab S11의 물리적 S Pen 필압/손바닥 접촉/고주사율.
4. iPhone 16 Pro의 물리적 WebKit/Safari 제스처·safe area·키보드·화면 회전.
5. 수십~수백 페이지 대형 PDF, 장시간 메모리·전력·Worker 크래시.
6. Artifex/법률 전문가의 AGPL 적용 범위와 대응 소스 고지·재현 빌드 최종 판단.
7. 운영 main 통합 및 Pages 배포는 **사용자 별도 승인 전까지 금지**이며 M7 범위에서도 임의 수행 금지.

## 7. 개발·검수 비중과 최종 판정

M6는 실제 공통 gesture/메모리/Worker·타일/UI 수정 코드를 우선 구현하고 영향받는 모듈의 필수 검사에 집중. 개발 60~70%, 검증 30~40% 목표를 지향했지만 **시간을 개별 계측하지 않아 비율 실측치라고 주장하지 않음**.

**M6 코드 개발 및 지정된 비운영 검증은 완료. M7 진입 가능.**
**공개 운영 적용은 AGPL 법률/소스 및 물리적 기기 검증 미완료로 차단.**
