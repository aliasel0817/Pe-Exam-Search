## 4. 보존·보안·라이선스 경계

1. **Google Sheets LIVE MASTER 원문, Drive PDF/이미지/첨부/실제 필기·학습정보:** 읽기·쓰기·삭제하지 않음.
2. **Apps Script:** 변경, 버전 생성, 배포, Script Properties 변경·공개하지 않음.
3. **운영 main / integration:** M5 개발 중 변경하지 않음. 모든 커밋·Push는 별도 M5 브랜치에만 수행.
4. **기존 owner-only 쓰기 정책:** M5는 server 변경 API를 호출하거나 정책을 변경하지 않음. 다만 운영 서버의 실제 owner guard 전체에 대한 새로운 라이브 감사는 수행하지 않았음.
5. **HTTP 캐시/Service Worker:** 기존 함수의 `cache:'no-store'`를 유지하며 사용자 원본·token·주석 파일을 새로 캐시하지 않음.
6. **AGPL:** Artifex 법적 해석(브라우저 MuPDF와 Apps Script 결합, 대응 소스 범위, WASM 재현가능 빌드)이 미해결이므로 **공개 MuPDF 배포 / 외부 프리뷰 금지**.
7. **현재 운영 PDF.js:** 운영 사이트가 여전히 구형 PDF.js 3.11.174를 사용하는 위험은 별도 과제이며 M5 작업이 해결하지 않음.

## 5. 아직 검증하지 않은 사항

- 실제 사용자의 ACTIVE 기기·운영 `mediaContent` 응답으로 원본 PDF가 열리는지: **미검증**.
- 실제 Google Drive 원본 PDF의 모든 케이스, 실제 저장된 필기와 서버 주석 동기화·저장/복원: **미검증**.
- Galaxy Tab S11의 실제 S Pen/손바닥 방지, iPhone 16 Pro Safari, 장시간 Memory·Worker 부하: **미검증**.
- 25MiB에 가까운 대형 PDF 및 매우 많은 페이지 수의 장시간 테스트: **미검증**.
- AGPL 법률 적합성 및 대응 소스 제공 완료: **미확정**, 공개 배포 NO-GO.
