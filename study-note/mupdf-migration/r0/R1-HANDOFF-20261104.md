## 4. R1 시작 시 기기·라이선스 GO/NO-GO 관문

1. 실제 Windows PC, Galaxy Tab S11, iPhone 16 Pro 연결 가능 여부 확인.
2. 각 기기를 직접 제어·관찰할 수 있는 검증 수단 확인.
3. 전달되는 JS/WASM이 외부 공개 또는 무허가 제3자 제공인지 검토. 적법한 격리 방식이 확인되지 않으면 전달·배포 금지.
4. 라이선스 판단이 불가능한 경우 MuPDF 실기기 검사는 BLOCKED로 기록하고, 허용된 합성 PC 검증 및 기존 앱의 비배포 확인만 진행.
5. 실제 원본 사용자 PDF·주석·인증서명을 외부 서버·Git·PR·로그에 남기지 않는다.

## 10. 반드시 지켜야 할 할루시네이션 방지 규칙
