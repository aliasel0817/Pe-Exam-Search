# R7 사용자 검수 안내 — 요청 2번·5번 (실제 PASS와 사용자 이관 분리)

기준일: 2026-11-04. 상태: USER-DEFERRED / 실제 기기 검수 미실행.
모든 테스트는 본인 계정과 승인된 테스트 자료에서만 수행. 인증키·서명 URL·원본 PDF 바이트·Google 계정 개인정보·실제 필기 자료를 제3자에게 전달하지 않음.

## 2번: 현재 운영 Apps Script 원본 PDF 제공 검수 (사용자가 지금 수행 가능)

운영 URL: https://aliasel0817.github.io/Pe-Exam-Search/study-note/study-note.html

1. 본인의 기존 **ACTIVE 신뢰기기**에서 로그인한 상태로 접속. 인증/장치 상태를 임의 변경하지 않는다. 새 PENDING/REVOKED 계정을 만들어 실서버 공격성 테스트를 하지 않는다.
2. **서브노트 원본 PDF가 등록된 토픽**을 선택하고 '서브노트 PDF 보기'를 누른다. 처음 썸네일을 표시한 뒤 **자동 원본 PDF.js 고화질**로 전환되는지 10초 정도 관찰한다. 개발 플래그나 추가 '고화질 보기' 버튼 조작 없이 열려야 한다.
3. 페이지를 앞뒤로 1회 이동하고, 확대 200%와 가능하다면 400%에서 문자/선이 썸네일 확대보다 선명한지 확인한다. 원본 PDF로 표시되면 페이지 제목·페이지 번호가 실제 원본과 일치해야 한다.
4. **교재 PDF가 등록된 다른 토픽**에서도 동일하게 열기→자동 원본→확대→페이지 이동 수행.
5. 결과 화면에서 '원본 PDF.js' 또는 '원본 고화질' 등 원본 표시 상태를 확인. 현재 운영 main에는 **MuPDF 기능이 아직 공개되지 않았으므로 'MuPDF.js 고화질' 표시를 기대하지 않는다.** 이 테스트는 운영 서버의 원본 PDF 제공 경로 검수이고 MuPDF 물리 기기 통과 판정과 다르다.

**PASS:** ACTIVE에서 서브노트·교재 모두 버튼만 눌러 원본이 자동 표시되고, 등록 페이지와 원본 내용이 일치하며, 확대 시 텍스트·선이 선명하고 이동·닫기·재열기가 정상.

**RECHECK/FAIL:** '미리보기' 또는 '원본 서버 확인 필요' 상태가 계속됨, 원본 파일 반환 오류, 빈/다른 PDF, 확대해도 이미지 픽셀만 커짐, 페이지 전환 실패, 무한 로딩, 인증 만료/미승인/권한 오류. 인증 미완료라면 먼저 신뢰기기 상태만 확인하고 비밀키를 공유하지 말 것.

**회신 형식:** `2번: 서브노트 PASS/문제, 교재 PASS/문제, 확대/페이지 PASS/문제, 화면 상태 문구, 오류 문구(개인정보 제외)`. 가능하면 개인 학습 자료 내용이 보이지 않도록 처리한 화면만 공유.

## 5번: 물리적 기기 검수 (승인된 비운영 MuPDF 파일럿 URL 제공 이후)

**중요:** 지금 운영 GitHub Pages에는 MuPDF JS/WASM이 공개되지 않았고 R7은 `BLOCKED`이므로, 현재 운영 사이트에서 5번 MuPDF PASS로 분류할 수 없다. 파일럿 URL, 정확한 버전/커밋, 테스트용 PDF와 테스트용 필기 자료가 준비된 뒤 사용자 검수. 현재 사이트는 과거 PDF.js 동작 비교용으로만 사용.

### 실제 Galaxy Tab S11 (S Pen)

1. Galaxy Tab S11 실기기 브라우저에서 파일럿 페이지 접속. 서브노트·교재·첨부 PDF 각각 처음 열 때 자동 고화질·1페이지 표시.
2. 테스트용 PDF에 S Pen으로 세 줄 그리기(약하게/강하게 눌러보기), 형광펜 한 번. 손바닥을 화면에 닿게 하면서 펜 입력을 시도.
3. 손가락으로 스크롤·핀치 확대(1x→2x→4x), 다른 페이지로 이동한 뒤 돌아오기, 가로/세로 회전.
4. 테스트용 필기 저장/복원을 허용한 격리 환경에서만 새로고침 후 필기가 동일 위치·색·굵기인지 확인.

**PASS:** S Pen 획 누락/튐 없이 압력 변화 반영, 손바닥의 불필요한 선 0건, 손가락 확대·스크롤이 펜 입력과 충돌하지 않음, 회전/페이지 복귀 후 필기 좌표 어긋남 없음, 무한 로딩/크래시 없음.

**RECHECK/FAIL:** 손바닥이 그려짐, 펜 획이 터치 스크롤로 인식됨, 확대 후 필기 위치 이동, 원본 품질 저하, 화면 깨짐·빈 페이지·브라우저 강제 종료.

### 실제 iPhone 16 Pro (Safari/WebKit)

1. 실제 iPhone 16 Pro Safari에서 파일럿 페이지 접속해 서브노트·교재·첨부 PDF 각각 열기. 첫 페이지 자동 고화질 확인.
2. 1x→2x→4x 핀치·스크롤, 앞/뒤 페이지, 가로·세로 회전 및 확대 위치가 가능한 한 유지되는지 확인.
3. Safari를 배경으로 보냈다가 복귀, 페이지 닫기·재열기, PDF.js fallback 테스트(파일럿에서 제공되는 경우).
4. 가능하면 테스트 전용 메모/형광펜 표시와 좌표 일치 확인. iPhone에 S Pen 필압 기능이 있다고 주장하지 않는다.

**PASS:** 세 종류 PDF 원본 렌더가 자동 표시되고 확대·스크롤·회전·복귀가 정상, 충돌·무한 로딩·필기 위치 어긋남 없음.

**RECHECK/FAIL:** 미리보기만 표시, 화면/페이지가 흰색·깨짐, 확대 위치가 비정상적으로 튐, 회전 후 주석 위치 불일치, Safari 재개 후 렌더 실패.

**회신 형식:** `5번 Tab S11: PASS/문제(문구), iPhone 16 Pro Safari: PASS/문제(문구)`. 반드시 실제 기기/브라우저 결과로만 PASS 표기.

## 수용 상태

- 2번: **DEFERRED_TO_USER, NOT YET PASS**. 사용자 결과 회신 시 확인 후 PASS/RECHECK 처리.
- 5번: **BLOCKED_UNTIL_PILOT, DEFERRED_TO_USER, NOT YET PASS**. 사용자 명시적 출시 위험 수용은 실제 실기기 PASS와 별도 기록.
