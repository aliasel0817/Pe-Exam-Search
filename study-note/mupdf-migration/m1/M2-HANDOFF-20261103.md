## 4. M2 개발 범위
A. MuPDF.js 공식 npm mupdf@1.28.1 버전 고정. 패키지 lockfile과 SHA-256 관리. 최신 보안 권고가 있으면 재확인 후 기준 버전 변경 이유 기록.
B. M3에서 사용할 JS/ESM + WASM 빌드·로딩/소스 제공 경로 설계 및 비운영 패키징(실제 PDF 렌더러 기능은 M3 범위).
C. 자체 호스팅 정적 asset 경로, Content-Type, 캐시 네임스페이스, PWA 버전 전략 설계. 인증된 PDF 데이터·signed GET URL은 Service Worker 저장 금지.
D. 라이선스 문서/저작권/NOTICE, 대응 소스 링크 및 사용자 소스 접근 UI 구현안. 법적 공개 범위가 미확정이면 사용자에게 배포되지 않는 비운영 시안에만 적용.
E. GitHub 공개 빌드 설정·비밀 설정 분리 및 재현 가능한 설치/빌드 명령. 실제 Script Properties와 .clasp.json 파일/Google ID·키 유출 금지.
F. M1 점검 도구를 M2 빌드 CI의 기본 안전 게이트로 연결. 실제 배포 artifact에 비밀이 없는지 검사.
G. 기존 PDF.js 버전 보안 경고 및 isEvalSupported:false 후보를 정리. 신규 병행 엔진 경로로 전개 시 보안 완화 필수.
H. 실제 소스에 근거하여 기존 라이브러리 PDF.js Apache-2.0, pdf-lib MIT, SheetJS CE Apache-2.0의 필수 고지 및 라이선스 파일 구성 확인.
