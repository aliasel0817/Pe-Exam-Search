## 5. AGPL 경계
- 공식 npm mupdf 1.28.1: AGPL-3.0-or-later, JS/ESM + WASM.
- Artifex는 서비스 제공 시 통합 앱 전체 대응 소스 공개를 요구하는 입장을 명시.
- 정적 프런트엔드와 Apps Script의 분리 네트워크 요청만으로 백엔드가 반드시 제외되는지 판정할 수 없음.
- 대응 소스에 실제 배포 WASM과 맞는 원본, 수정, 빌드 스크립트, 의존성 라이선스·고지를 포함하도록 M2 설계.
- 공개 대상에서 사용자 PDF, 필기 데이터, Secret/Script Properties, 인증 토큰, 개인 저장소를 제외하고 프로그램 소스 범위를 법률 검토.
- 법률적 확정 전 무상 AGPL 방식으로 MuPDF WASM을 외부 공개 배포하지 않음. 불가 시 상용 라이선스 검토.

## 6. 추가 보안 위험
- PDF.js 3.11.174는 CVE-2024-4367 영향 범위. getDocument의 isEvalSupported:true 기본 사용 시 악성 PDF JS 실행 위험.
- 후보 패치는 참고 PDF와 첨부 PDF의 두 로더에 isEvalSupported:false 적용. 패치 적용성 확인만 수행.
- 실제 운영 완화와 테스트는 별도 승인하에 적절한 보안 변경 단계에서 추진. M1에서 운영 UI 변경 없음.
