# R4 — 사용자가 수행할 실기기·인증 검수 항목 (준비용)

**작성일:** 2026-11-04 (Asia/Seoul)
**현재 앱 상태:** 운영 GitHub Pages는 구형 PDF.js 경로 유지, MuPDF.js는 비운영 loopback에서만 사용 가능. **실기기 시험을 위해 공개 서버로 MuPDF JS/WASM을 제공하면 안 됨.**
**필수 선행:** Artifex/법률 검토 또는 유효 상용 계약, 적법한 개인 기기 제공 방식, 격리 테스트 원본·필기 백업/복구, 사용자의 별도 승인.

## A. 사용자가 우선 확인할 사실 (지금은 안전한 준비 단계)

1. **Galaxy Tab S11 실제 기기**: 소유자 확인, OS/브라우저 버전, PC USB 디버깅 사용 가능 여부, S Pen 원본 필압 지원 여부. 앱에 운영 PDF/필기 테스트 입력은 하지 않음.
2. **iPhone 16 Pro**: iOS 버전, Safari 버전, 실제 디바이스 접근/화면 녹화 가능 여부, 비공개 개발 기기를 적법하게 연결할 방법. Safari UA 에뮬레이션은 실기기 검증이 아님.
3. **Windows Chrome**: USB로 연결된 개발 PC 또는 사용자 집/회사 PC에 실제 Chrome 이용 가능 여부 확인. 현재 R4 고지 UI는 Windows Chrome 156 합성 테스트 PASS.
4. **안전한 테스트 자료**: 실제 LIVE MASTER 및 실사용 주석과 별개인 1~2장 합성 PDF와 독립 테스트 계정/기기 및 백업/복구 수단 준비.
5. **법률 선택**: AGPL 준수로 앱/필요 소스 전체 공개에 동의하는지, 아니면 Artifex 상용 라이선스를 확보할지 결정. 비밀정보 노출 없이 설치·빌드 가능한 소스 제공 방식 서면 검토.

## B. 적법한 격리 시험환경 확보 후에만 실행할 최소 기능 검수

| 기기 | 핵심 동작 | 결과 기록 |
|---|---|---|
| Windows PC 실제 Chrome | 서브노트·교재·첨부 PDF 최초 고화질, 확대 1x/4x/10x, 페이지·첨부 전환, PDF.js fallback, 필기 표시·종료 | PASS/FAIL, 브라우저 버전, 실제 PDF 종류(내용은 기록 금지) |
| Galaxy Tab S11 | 실제 S Pen 기본 필기·필압, 손바닥 접촉, 한 손가락 스크롤, 두 손가락 핀치, 세로/가로 전환 및 주석 좌표 | PASS/FAIL, OS, 브라우저, 필압/좌표 오차 |
| iPhone 16 Pro Safari | 실제 Safari/WebKit PDF 표시, 스크롤·핀치·회전, safe area, 배경 전환 후 복귀, 기존 휴대전화 필기 정책 | PASS/FAIL, iOS/Safari 버전 |
| 격리 Apps Script | 승인된 ACTIVE signed GET 실제 PDF 반환, 만료/잘못된 서명/REVOKED 거부, owner-only 정책 | PASS/FAIL, 응답 코드·익명화된 결과만 기록 |
| 격리 주석 서버 | 사용자·페이지·첨부별 schema3 필기 저장·재열기·복원, 원본 미변경·되돌리기 | PASS/FAIL, 복원된 합성 주석 개수·좌표 오차 |

## C. 결과 보고 양식

- 검수일시, 실제 물리 기기 모델 및 브라우저·OS 버전
- 라이선스상 허용된 테스트 제공 방식 / 비공개 네트워크 확인
- 테스트 대상은 **합성 PDF·격리 필기**만
- 검수 범위: 기본 열기/전환/확대/필기/복귀
- 각 항목: PASS, FAIL, NOT VERIFIED, BLOCKED, DEFERRED
- 오류 재현 단계와 화면 캡처(사용자 이름·토큰·원본 PDF·필기 내용 익명화)
- 데이터 쓰기 발생 여부와 복구 증거

**주의:** 현재 상태에서 운영 사용자의 필기를 테스트로 저장/삭제하거나 ACTIVE GET을 무단 호출하지 마세요. 버전21 인증 로직은 GET 시 보안 기기 ‘마지막접속일시’가 갱신될 수 있습니다.

## D. R4 완료 판단과 출시 판정의 차이

R4 코드·고지·인계서 및 비운영 Chrome 검사는 개발 단계로 완료할 수 있다. 물리 Tab/iPhone, LIVE ACTIVE PDF, 필기 서버 영속성은 사용자가 직접 격리 시험을 마치고 근거를 제공해야만 PASS 처리할 수 있으며, 그 전에는 **NOT VERIFIED/BLOCKED**로 남긴다. 서비스 공개는 모든 필수 조건과 별도 운영 승인 후 다음 단계에서만 가능하다.

불필요한 전체 배율/해상도 전수·장시간 배터리·미세 UI 검사는 승인된 파일럿/실사용으로 미뤄도 되지만 인증/데이터 보존/라이선스 안전 검사는 미루지 않는다.
