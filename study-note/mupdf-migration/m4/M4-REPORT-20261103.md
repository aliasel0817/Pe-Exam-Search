## 4. 기존 정보·보안 보존
- `main` 및 `integration/mupdf-migration`는 작업 전 그대로 두며 운영으로 push/merge/deploy 없음.
- Apps Script 코드를 읽기/변경한 작업 없음, Script Properties·서버 비밀정보에 접근하지 않음.
- Google Sheets LIVE MASTER, Drive의 실제 PDF/이미지/첨부, 학습정보 및 실사용자의 저장된 필기 데이터를 읽거나 수정하지 않음.
- 현재 운영 공개 사이트의 기존 PDF.js 3.11.174는 *그대로* (취약점 관련 운영 패치/전환은 별도 승인·계획 필요).
- Browser QA-only `window.__M4_REFERENCE_QA__`는 loopback+opt-in에서만 제공. 로컬에서 메모리 합성 PDF를 넣어 실 HTML을 테스트할 뿐, 운영 signed GET 우회 코드를 추가하지 않는다.
- M2 AGPL 공개 배포 차단 게이트 유지, 대응 소스/Apps Script 결합범위 법적 검토 미완료. Public release NO-GO.

## 5. 아직 검증하지 않은 범위
1. 실제 사용자 로그인 기기에서 원본 signed GET이 서버/신뢰기기 인증과 함께 성공하는지 (이번 단계는 실제 인증 상태를 사용하지 않음).
2. 실사용자 PDF와 기존 필기 데이터 전량 호환성 및 극단적 페이지 파일 검증.
3. Galaxy Tab S11 실제 S Pen, iPhone 16 Pro Safari 터치/핀치 및 모바일 메모리.
4. Worker 중단/재시작 장시간 반복, 100페이지 이상 대형 문서 체감성능(현행 referencePdf API는 1페이지 단위).
5. AGPL Apps Script 결합범위, MuPDF C/WASM 대응 소스 완전성 및 법적 검토.
6. 최종 운영 적용/대외 공개는 사용자 별도 승인 후 M7.
