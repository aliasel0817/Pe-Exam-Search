## 4. M5 목표
**기존 첨부 PDF 보기**를 새 공통 MuPDF 렌더러로 실제 연결한다 (M4 서브노트/교재는 그대로 보존). 다음 모두 유지:
- 첨부 PDF 목록·순서·선택 및 파일ID/attachmentId 매핑
- 페이지 이동(멀티페이지)
- 첫 로딩부터 고화질, 확대/축소·fit/스크롤·PC 마우스
- 터치/핀치 및 S Pen 필기 오버레이(실제 기기 종합검수는 M6/M7)
- 주석 schema 3 및 `normalized-0-1`, 기존 저장/복원 키 `attachment-pdf:<attachmentId>:<pageNumber>`
- 기존 `fetchMediaContent(getApiUrl(),item.attachmentId)`와 서버 인증·변경 권한 유지
- PDF.js 6.5.438 복구 경로 및 안전한 에러 UI
- Google Sheets LIVE MASTER, 이미지/첨부 원본, 필기 데이터 무변경

## 5. M5 단계별 실제 개발 범위

### M5-1. 기존 첨부 PDF 함수 경로 정밀 확인
실제 `study-note/study-note.html`에서 함수 이름으로 최신 위치 확인:
- `openPdfAttachments`, `openMediaViewer` 등 첨부 PDF 진입 함수
- `loadAttachmentPdfPage` 및 `repaintAttachmentPdfAtZoom`
- `computeAttachmentPdfRenderMetrics`
- `ensurePdfJsLoaded`, 기존 PDF.js `getDocument`
- attachmentId 기반 `fetchMediaContent`, 페이지 navigation, `closeMediaViewer`
- `ensureAnnotationSurface`, `annotationSurfaceKey('attachment-pdf',...)`, 주석 동기화
- 브라우저 캐시/Service Worker, pinch, page switch 자원 해제

M4가 수정한 reference PDF 로직은 변경하지 않고 최대한 재사용한다.

### M5-2. 첨부 PDF 공통 렌더러 연결
- M3/M4 공통 어댑터를 재사용해 첨부 PDF Uint8Array를 신규 MuPDF 세션으로 열기.
- 새 attachment viewer 전용 모듈 생성 권장. 기존 referencePdf 의존 DOM 조작을 무리하게 공유하지 않는다.
- Multi-page `countPages`, 1-based 페이지 이동, 페이지별 CropBox·rotation·viewport 크기 반영.
- Worker 우선/불가 시 main-thread MuPDF/실패 시 안전한 PDF.js 6.5.438 fallback 명확히 구현.
- 실제 표시 엔진과 복구 상태를 UI에 명시한다.
- **별도 비운영 개발 모드에서만 실행**; AGPL 외부 공개 불가 시 `m4-local`과 같은 loopback 보안 플래그로 차단.

### M5-3. 확대·축소·타일·필기 유지
- 최초 DPR 기반 고해상도 렌더링 및 page-fit/width-fit.
- 오래된 전체화면 단순 확대에서 글자 품질 저하를 방지할 수 있도록 M3/M4 `normalized` region 타일 로직 적용.
- 기존 필기 오버레이는 PDF 변환과 별도 유지. schema 3, normalized-0-1, 원본 annotationId 및 페이지 키/pressure/widthN·도형/형광펜/노트 저장 구조 모두 보존.
- 스크롤/zoom/rotation 동안 PDF와 주석의 오버레이 좌표 정합 검증.
- 페이지·첨부 전환, 모달 close 때 렌더 요청 취소·Worker·Document·Pixmap 해제. 예전 페이지 응답이 현재 페이지를 덮어쓰지 않도록 serial 검사.
- 메모리·픽셀 budget(기존 M3/M4 기본값)과 오래된 타일 해제.

### M5-4. 원본 API·보안 보존
- 기존 `fetchMediaContent` 서명·권한 정책을 그대로 호출. 관리자/owner 변경 API는 건드리지 않는다.
- 공개 조회 정책을 일괄 제한하지 않고 기존 서버 권한 유지.
- signed URL, 인증 토큰, 사용자 PDF blob, 주석을 Service Worker/공개 로그/CI에 넣지 않는다.
- 실제 운영 Apps Script 소스 변경과 배포 절대 금지.
- 기존 PDF.js 3.11.174 운영 경로는 무방비 복구용으로 재사용하지 않고 새 안전한 6.5.438 경로 사용.

### M5-5. 개발 중심 테스트 및 PR
- 새 임시 Git 분기, private M2 stage, M3 의존성 재설치.
- 합성 멀티페이지 PDF (회전·CropBox·다양한 크기)로 페이지 이동·zoom·tile·annotation schema·fallback·close 검증.
- 실제 Chrome에서 **현행 학습노트 첨부 PDF 모달**을 격리한 loopback 테스트; 외부 Apps Script/Drive와 데이터 쓰기 차단.
- 필요 시 민감정보 없는 허가된 PDF 샘플로만 읽기 테스트, 실제 기기 테스트는 M6/M7.
