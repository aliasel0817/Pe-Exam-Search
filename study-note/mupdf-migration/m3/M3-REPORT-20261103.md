## Implemented code
- m3-common.mjs: uniform renderer errors and sanitized PDF bytes, size/edge/pixel budget, normalized<->pixel and normalized<->CSS transforms, RGBA copies and ImageData painting.
- m3-mupdf.mjs: actual official MuPDF 1.28.1 PDF byte opening and page count, page rotation/CropBox/MediaBox, native Page/Pixmap/DrawDevice, full/region rendering, explicit close/destroy of page/pixmap/document and budget validation.
- m3-pdfjs.mjs: independent fallback using **pdfjs-dist 6.5.438** instead of unsafe operating 3.11.174, always isEvalSupported:false, page render/cancel/cleanup, browser/Node canvas factories.
- m3-engine.mjs: common opening/routing with explicit primary/fallback engine and failure reason, no automatic fallback for abort signals.
- m3-worker.mjs / m3-worker-client.mjs: browser Worker messaging, transferable RGBA buffer, cancellation by Worker terminate and on-demand reopen, no live signed URL persistence.
- tests/fixtures.mjs: PDF synthesized in memory with vector/text and rotated CropBox; never uses actual user data.
- tests/renderer.test.mjs & routing-worker.test.mjs: 16 tests covering render, high zoom, tile versus full pixels, metadata, crop, rotate, annotations normalized-0-1, Worker abort, engine switch.
- tests/browser-smoke.mjs & harness.html: real Chrome test with three rendered canvases; local-only 127.0.0.1 ephemeral HTTP.
- tests/benchmark.mjs: independent synthetic PDF zoom/budget benchmark.
