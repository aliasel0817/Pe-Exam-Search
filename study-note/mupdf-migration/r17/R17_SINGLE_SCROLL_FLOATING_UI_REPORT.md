## 사용자 요청과 개선 방식

R14/R15는 토픽 관리 팝업 안에 별도의 스크롤 프레임과 하단 이동 바
공간이 있어 기존 개념·등장배경·특징 등 편집 화면의 표시 영역을 줄였음.
R17은 기존 **토픽 관리 단일 스크롤 카드**를 복원하고, 그 위에
메인 화면 이동 바와 같은 작은 `▲ ▼ ▶` 캡슐을 **절대 위치 오버레이**로
띄움. 캡슐 때문에 예약하는 하단 높이는 **0px**이며 좁은 화면에서도
별도 세로 스크롤바가 생기지 않음.

- `#manageModal .manage-shell`: 카드와 작은 캡슐을 묶는 비스크롤 위치 기준
  요소이며 별도 프레임/입력 필드/스크롤 영역이 아님.
- `.manage-card`: 기존처럼 자체 세로 스크롤을 하는 **유일한 스크롤 영역**.
  헤더와 저장·취소 버튼도 동일 스크롤 영역 내 위치.
- 기존 `#manageScrollBody`: 이전 코드 호환을 위해 HTML 노드는 그대로
  두지만 CSS `display:contents`로 렌더 박스·스크롤 영역은 생성하지 않음.
- `.manage-quick-scroll`: 바깥 쉘에 absolute 배치.
  저장·취소·학습대상 N 버튼이 보이면 실제 위치를 측정해 캡슐을
  해당 버튼 행 **위쪽으로만 조정**하여 클릭을 가리지 않음.
- ▲·▼는 유일한 `.manage-card.scrollTop`만 변경.
  펼침 시 `▲ ▼ ▶`, 숨김 시 `◀`. 기존 ARIA/키보드/44×44px 터치 영역 유지.
- 기존 입력 필드/첨부자료/유형 구분/저장 로직/PDF 뷰어/주석/API 변경 없음.

## 사용자에게 제공하는 구조적 개선

원래 R15의 플로팅 **처럼 보이는 하단 예약 영역**과 달리 R17은
진짜 오버레이이므로 팝업 높이와 가용 스크롤 높이를 낭비하지 않음.
사용자가 원래 원했던 하나의 토픽 관리 프레임으로 스크롤 작동.
