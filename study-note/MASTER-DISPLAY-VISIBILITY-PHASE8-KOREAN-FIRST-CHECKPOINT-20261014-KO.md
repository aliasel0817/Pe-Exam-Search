## 2. 구현된 화면 전용 개선

1. A안 기존 목록 `<ol>`을 유지하여 X/Y의 독립 항목을 줄 단위로 렌더링.
2. 기존 번호/하이픈이 이미 있는 다중 줄 원문은 다시 번호를 붙이지 않고 `white-space: pre-wrap`으로 개행·들여쓰기 보존.
3. Y 기술요소명에 대해 검증된 `English(한글)` 대응을 `**한글** (English): 설명` 순서로 표현. 영문 기술명은 흐리고 작게 보조 표시하되 **삭제하지 않음**.
4. 한글 대응을 표시 우선으로 전환하는 근거는 **해당 원문 명시 병기**, **같은 토픽 키워드의 정확한 쌍**, 또는 **같은 토픽 특징의 정확한 쌍**만 사용. 일반 사전 추정만 있는 대응은 우선순위 뒤집기 금지.
5. 약어·표준/버전 숫자 등의 이름은 영문 원문 우선으로 유지. 중첩 괄호·설명 원문은 그대로 유지.
6. 목록별 DOM `data-study-original-item`에 원문 요소 전체를 남겨 화면 단계 가역성 검증 가능. HTML 실행/삽입 대신 `textContent` 사용.
