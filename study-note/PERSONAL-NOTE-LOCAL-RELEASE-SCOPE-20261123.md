# 개인 노트(그림판) 운영 프런트엔드 릴리스 범위 기록 — 2026-11-23

## 이 릴리스가 제공하는 기능 (브라우저 로컬 버전)
- 개인메모 행 왼쪽의 **개인 노트** 버튼, 토픽명 팝업, 취소만 닫기.
- 토픽 통합 ID별 여러 페이지, 공통 배경 이미지(전체 토픽 공통), 공통 체크 기본 ON.
- 펜·형광펜·도형·글자·사진·복사이미지 붙여넣기·객체 이동/사진 크기·지우개·undo/redo.
- IndexedDB `pe-personal-note-db` 별도 보관, 현재 페이지 PNG, 토픽별 편집가능 JSON 백업/복원.
- 기존 학습 원문, 주석, 진도, PDF, 첨부·인증·동기화 DB와 분리.
- 서비스워커의 새 개인 노트 JS/CSS 및 클라우드 호환 코드는 원래 오프라인 캐시 정책에 맞춰 사전 캐싱.

## 중요 — 기기 간 공유 기능은 아직 운영 제공하지 않음
- `personal-note-cloud.js`는 **ACTIVE 인증된 서버 지원 여부를 탐지**하고, 서버 미지원이면 로컬 저장만 실행.
- 현재 운영 Apps Script 전체 v23 소스를 확보·검증하지 못했음. 신규 서버 애드온 2개는 `study-note/backend/`의 **소스 후보**이지 운영 Apps Script로 자동 배포되지 않음.
- 서버 애드온은 `ISOLATED_TEST`만 허용하므로 실운영에 배포/연결하지 않았음. 운영에 `PERSONAL_NOTE_SYNC_MODE` 등의 속성을 추가하지 않았음.
- 따라서 사용자에게 **다른 PC/태블릿/스마트폰에서 저장된 동일한 개인 노트가 자동 동기화된다고 안내하지 말 것.**
- 이 기능은 현재 사용 중인 브라우저 저장소에서만 지속. 브라우저 데이터 삭제/캐시 제거/프라이빗 모드/기기 교체 때 유실될 수 있으므로 노트 작성 후 **JSON 백업** 권장.

## 개발/테스트(합성 검사; 실제 사용자 데이터 0건 쓰기)
- GitHub Actions 개인 노트 체크, 합성 Chrome 단독 및 전체 학습노트 페이지 클릭/저장/재열기 PASS.
- 기존 PDF 업로드·가시성·WebKit·Windows 오프라인/캐시 중 현재 실행된 기본 검사 PASS 기준으로 확인.
- 일부 R6/R9/R17 MuPDF 불변성 검사는 **새 HTML/CSS/JS를 포함한 이전 원문 byte-for-byte 고정 테스트**가 실패할 수 있음. 기능 회귀 테스트 PASS라고 대체 표현 금지. 원본 PDF/기존 주석 코드는 수정하지 않았음.
- 물리 기기(PC, Tab S11, iPhone Safari), 실제 ACTIVE 신뢰기기 왕복, 실제 Apps Script 동기화, 실제 GitHub Pages 게시 결과는 별도 검증 필요.

## 운영 연결 후속 (별도 작업)
1. 실제 최신 운영 Apps Script v23 소스·배포버전 읽기 전용 확보, 기존 서버 인증/HMAC·nonce·mutationStatus 동작 비교.
2. 별도 사설 시험 Drive 폴더와 독립 Apps Script 환경에 candidate `personal-note-sync-isolated.addon.gs` + signed bridge 설치·검증.
3. Google 서버에서 두 기기 실라운드트립, 충돌·이미지 무결성, 운영 데이터 보존 검사.
4. 승인된 별도 PR에서 운영용 API/배포 패키지 작성(개인 노트 전용 개인 데이터 저장소), 사용자가 승인한 경우에만 실제 운영 Apps Script에 반영.
5. 검증 완료 전까지 서버 저장 성공·다중기기 공유 완료라고 주장하지 않음.
