## 2. T1923 — Zero-shot/One-shot/Few-shot Learning (AI, 행 1824)

- **원천 교재 직접 확인**: `AI-1:211` / `AI-1_0211.pdf`의 텍스트층은 **소량의 학습표본으로 새로운 *클래스*를 분류하는 ML 설정**을 중심으로 대조함. 원본의 기법:
  - Zero-shot: 기존 모델의 **시맨틱 임베딩 / 속성 기반 학습 / 전이 학습**을 이용한 미관측 클래스 분류.
  - One-shot: **클래스당 단일 이미지/표본**, Siamese Networks/Matching Networks.
  - Few-shot: **클래스당 소수 이미지/표본**, Prototypical(원형) Networks/Matching Networks 등.
- 현재 LIVE J는 일반적 0/1/소수 예시 학습을 설명하지만, X/Y의 상세 요소는 **LLM 프롬프트에 예시를 넣는 In-context Learning**에 집중. 그 자체는 유효한 분야지만, **교재의 클래스 분류·메트릭 학습·메타학습 유형 지식이 Y에 명시되지 않는 문제**.
- Google ML Glossary는 `few-shot learning`(소량 사례에서 분류모델 학습)과 `few-shot prompting`(LLM에 몇 개 예시를 포함하는 프롬프트)을 구분. GPT-3 논문은 *특정 few-shot inference 설정에서* 가중치 갱신 없이 프롬프트만으로 처리한다고 설명함. **이 성질을 일반 Few-shot Learning 전체의 필수조건이라고 확대 해석하면 안 됨**.
- **보존형 Y 추가 시안 (7번째 요소 후보)**:
  - `학습 설정·대표기법 구분(Zero-shot은 의미임베딩·속성 기반 미관측 클래스 분류, One-shot은 1개 학습표본 기반 Siamese·Matching Network, Few-shot은 소수 표본 기반 Prototypical·Matching Network 등 모델 적응; LLM In-context Learning은 예시를 프롬프트에 제공하는 별도 사용방식)`
- 사전검사: 기존 LIVE Y의 **6개 핵심 요소명 모두 식별**, 시안은 **뒤에 1개 요소만 추가**, 기존 6개 역할설명 글자 단위 변경 없음. 추가 시 실제 렌더러가 7개 요소를 가독성 있게 보여주는지 별도 QA.
- X에 일반 Few-shot Learning vs LLM Few-shot Prompting의 **학습환경/가중치 변경 여부/예시 제공 위치**를 설명하는 항목을 추가할 수 있으나, 교재 표·그림의 원문과 현행 기술분류를 확인한 뒤 별도 확정.
- **원본에서 '환각'으로 표기된 기법은 문맥 미확정 용어이므로 무조건 최신 Y에 복제하지 않음.** 원문 PDF 화면 도식 시각검수와 과거 교재 내용 맥락 대조가 후행.
- 원천 근거: 교재 `AI-1:211` (텍스트층), https://developers.google.com/machine-learning/glossary , https://arxiv.org/abs/2005.14165
- 등급: **상 — 동일 토픽명 아래 학습설정 범위 차이**. 오류 확정은 LLM 내용 자체가 틀렸다는 의미가 아니라, **연결 원본의 분류 기반 학습 지식이 Y에 충분히 남지 않은 후보**임.
