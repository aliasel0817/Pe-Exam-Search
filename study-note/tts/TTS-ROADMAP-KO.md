# 학습노트 AI 자연음성 TTS — 남은 주요 9단계 계획

기준: 2026-10-09, 운영 v4.6.3 / 개발 feature/ai-natural-tts-20261009

## 이미 완료한 기반

- us-central1 비공개 GCS 버킷 + CORS + 최소 권한 런타임 계정
- 전용 Cloud Build 서비스 계정 + Cloud Run 1개 게이트웨이 배포
- 무인증 MP3 목록 HTTP 401 / 허용 GitHub Pages CORS / 브라우저 OPTIONS 204 실제 검증
- 학습노트 TTS UI 및 재생 컨트롤 초안, Python TTS MP3 생성기와 비공개 업로드기, Cloud Run 음성 조회 게이트웨이 **코드** 작성
- Google 로그인용 격리 HTML 파일 `tts-auth-check.html`만 운영 main에 추가한 GitHub 커밋 55052c05c2b4330fe9798161b2ab4565076a852d 확인
- 운영 PWA HTML/JS, PDF·필기 데이터, Apps Script, 기기 인증 설정은 변경 없음

## 현재부터 프로젝트 종료까지 **9개 주요 단계** (진행률 추정치가 아닌 검수 단위)

| 단계 | 주요 작업 | 완료 기준 | 사용자 참여·승인 |
| --- | --- | --- | --- |
| 1. 실제 Google 로그인 인증 | GitHub Pages의 독립 테스트 HTML에서 기존 Google 웹 OAuth ID로 Cloud Run 계정/allowlist 검증 | 허용 Google 계정은 서버 인증 통과, 허용되지 않은 계정은 거부. 음성/GCS 쓰기 없음 | 본인 계정으로 로그인 후 **오류코드만** 보고 (토큰·이메일 전송 금지) |
| 2. 읽기 데이터·목소리 검수 | 토픽명 + 개념·등장배경·필요성·특징·기술요소/구성요소·키워드 필드 순서 확인, SQL/MCTS/LSM-Tree 사전과 2~3 목소리 후보 선정 | 샘플 5~10 토픽과 발음 규칙 확정, 원본 셀 변경 없음 | 음성 목소리·읽기 문구 선호 결정 |
| 3. 소량 AI MP3 생성 | 승인받은 5~10 토픽의 **선택한 항목 단위** Chirp 3 HD 음성 합성 및 길이·음질 확인 | 한 번 생성한 MP3를 재사용, 생성량·건수·비용 모니터 기록 | TTS 실제 유료 가능 호출에 **별도 명시적 승인**, 청취 품질 확인 |
| 4. 비공개 MP3 저장/조회 | GCS에 시험 MP3 및 GCS index.json 업로드, Cloud Run 5분 Signed URL, 콘텐츠 SHA 검증 | 신뢰 계정으로만 MP3를 재생할 수 있고 재생 중 추가 합성 API 호출 없음 | GCS MP3 시험 업로드에 **별도 명시적 승인** |
| 5. 학습노트 재생 UI 연동 | dev HTML에 스피커/설정·본문 항목 체크·현재 토픽 재생, 기존 문제검색·PDF·주석 UI 충돌 점검 | 운영 main 무변경 상태에서 개발 테스트 통과 | PC·태블릿에서 UI 확인 |
| 6. 학습 재생 컨트롤 | 토픽명 항상 첫 번째, 선택 본문만 고정 순서로 읽기, 연속재생·반복·속도·회상 간격·필터/자동넘김 | 중지·수동 이동·편집 중 오동작 없음, 저장된 필드 선택 재사용 | 학습 패턴 점검 |
| 7. 캐시·동기화·비용 제어 | 공용 MP3/기기별 캐시, 변경된 내용만 재생성, 비정상 호출·중복 요청 방지, 생성량/저장량 로그·백업 | PC/갤럭시 탭/iPhone이 같은 서버 MP3를 사용, 무료/비용 주의 문서화 | 오프라인 범위와 실사용 정책 검수 |
| 8. 멀티디바이스 최종 QA | Windows, Android, iOS Safari에서 로그인·동작·화면 잠금·PWA 재시작·복원·회귀 검사 | 중요 장애 0, 예상 제약 명시, 운영 복원 경로 검증 | 실제 3종 기기 확인 |
| 9. 운영 배포·음성 범위 확대·인수 | TTS 기능을 플래그/롤백 가능한 상태로 main에 배포, 기존 앱 유지 확인, 학습대상 약 3,800 토픽의 MP3를 단계적으로 생성 | 사용자 수용검사 통과, 샘플·일괄 음성 커버리지 목표 및 백업/복구 문서 확정 | 운영 반영 승인 및 유료 한도/월간 생성 정책 확정 |

9개는 **기능 단위**이며 여러 개 명령을 한 번에 처리할 수 있음. 단순한 사용자 설정과 읽기 전용 조회는 함께 처리. 실제 새 유료 리소스·음성 생성·GCS 업로드·운영 main에 영향을 주는 변경은 범위별로 별도 확인.

## 프로젝트 종료 정의
- 학습노트 실사용 TTS가 토픽명 먼저, 선택한 6개 본문을 지정 순서로 자연음성 MP3 재생
- 공통 GCS 파일은 모든 기기에서 동일하게 재사용되며 신규 합성은 내용 변경 또는 신규 토픽인 경우만 실행
- 클라우드비와 호출량 추적, 비공개 자료·인증 보호, 사용자 동의한 최대 비용 범위 초과 방지 정책 확인
- PC, 태블릿, iPhone QA 통과 및 운영 복원/백업 자료 준비
- 학습대상 약 3,800개 음성 파일 확보는 월 무료 제공량·허용 예산에 따라 여러 번의 분할 배치가 필요할 수 있으며, 전체 일괄 생성이 즉시 가능한 일정이라고 보장하지 않음

## 절대 금지와 현재 잠금
- `ttsGenerationApproved=false` — 실제 자연음성 합성 호출 금지
- `gcsUploadApproved=false` — 실제 MP3 / index.json 업로드 금지
- `cloudRunRevisionUpdateUserApproved=false` — Cloud Run 새 리비전 재배포 금지
- `cloud-config.json.mode=disabled` — 운영 학습노트와 클라우드 게이트웨이 미연결
- 운영 main의 PWA 코드·Sheets·필기·Apps Script·기존 기기 인증 설정 보호

## 바로 다음 사용자 작업
1단계: 배포가 완료된 후 `https://aliasel0817.github.io/Pe-Exam-Search/tts-auth-check.html`에서 Google 로그인 시도.
서버가 허용한 **Cloud Shell 활성 Google 계정**으로 로그인하는 것이 좋음.
결과 화면의 HTTP 503(Audio manifest unavailable)라면 정상적인 인증 이후 아직 MP3 인덱스 미업로드 상태일 수 있음. 403이면 이메일 allowlist 또는 OAuth token audience 확인. 인증 토큰과 계정 이메일은 화면에 노출·공유하지 않음.

인증 완료 시 2단계의 콘텐츠/음질 샘플부터 순차 진행. 실제 음성 합성·업로드는 그때 별도로 승인받음.
