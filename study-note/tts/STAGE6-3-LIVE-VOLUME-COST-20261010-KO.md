이 수치는 **기존 12개 MP3 재사용을 반영하지 않은 전체 신규 제작 상한 계획**이다. 현재 공개 개발 저장소의 매니페스트는 비어 있고, 실제 GCS 비공개 매니페스트 항목 8개는 인증된 별도 비교가 필요하다.
특히 `T1961`, `T2354`의 제목 변경은 정확한 과거 원문·음성 SHA와 경로가 일치하는 경우에만 재사용해야 한다. 다른 원문 불일치는 절대 재사용하지 않는다.

출처: https://cloud.google.com/text-to-speech/pricing

- **한 달에 전량 신규 합성하고 그달 무료 100만 자를 전부 이용할 수 있다면:** (4,724,944 - 1,000,000) × 0.00003 = **US$111.74832 ≈ US$111.75**.
- **그달 무료 할당량을 전혀 이용할 수 없다면:** 4,724,944 × 0.00003 = **US$141.74832 ≈ US$141.75**.
- 이미 생성한 12개 MP3 및 남아 있는 월 무료 사용량에 따라 실제 청구 문자·금액은 달라진다.
- MP3 GCS 저장량·객체 수·다운로드/네트워크·Cloud Run·세금 및 환율은 이 TTS 문자 과금 추정에서 제외.
- 정확한 유료 실행 범위와 비용은 **실제 비공개 매니페스트와 최신 원문을 재검증한 후 별도 승인**해야 한다.

## 6. 6-4 이전 반드시 해소할 사항

1. **6-2 실기기 QA**: 운영 PWA에서 Windows PC / Galaxy Tab / iPhone의 인증된 MP3 재생·연속 읽기·정지/중단 확인.
2. **비공개 매니페스트 검증**: 기존 8개 항목/12개 MP3를 원문·speech SHA·파일 경로 및 객체 존재 기준으로 일치 검증. 불일치는 안전 중단, 무단 재합성 금지.
3. **유료 제작 승인**: 도메인·항목·합성 문자 수·UTF-8 바이트·최대 API 호출 수·최대 예산을 한 배치 단위로 확정. 승인되지 않은 비용 발생 금지.
4. **생성 도구 범위 재설계 필요**: 현재 `generate_mp3.py`는 한 실행 최대 50토픽/200요청, **월 UTF-8 50,000바이트 안전 제한**, `ttsGenerationApproved=false`, `gcsUploadApproved=false`. 전체 제작을 위해 이 제한을 임의 해제하지 않는다.
5. **증분·불변 업로드 설계**: `sourceHash`와 `speechHash`가 검증된 미생성 항목만 처리하고, 기존 MP3 삭제/덮어쓰기 금지, 업로드와 index 변경은 원자적 검증 후 승인 범위에서만 실행.
