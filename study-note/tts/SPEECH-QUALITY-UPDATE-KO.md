# TTS 음성 품질 보정 (2026-10-09)

개발 브랜치 `feature/ai-natural-tts-20261009` 전용. 운영 `main`, Google Sheets 원문, Cloud Run, GCS 및 기존 MP3 35개는 변경하지 않음.

## 입력 전처리 (Google Sheets 원문 및 원문 해시 불변)
- 짧고 확실한 영문(한글) 용어는 한글만 발음. 단독 영문은 기존 발음 사전을 사용.
- `SQL(구조화 질의 언어)과` → `구조화 질의 언어와`. 받침 및 ㄹ 받침 예외에 따라 은/는, 이/가, 을/를, 과/와, 으로/로 조정.
- 한 글자 변수, 복잡한 괄호, 혼합 문자, 불명확한 붙임말은 변환하지 않음. 이 규칙은 완전한 한국어 문법 분석기가 아니므로 최종 샘플 청취 필요.
- 원문의 `·`를 쉼표 + `[pause short]`로 변환하고, 해당 문장이 포함되면 Google Chirp 3 HD REST 요청에 `input.markup` 사용. `input.text`에서 pause 태그는 동작하지 않음.
- 220글자 또는 4,200 UTF-8바이트 이내로 구간 분할. 문장부호와 띄어쓰기 경계 우선, 태그 중간 자르기 금지. 분할된 구간은 기존 `files` 매니페스트 구조로 순서대로 재생.
- 쉼의 실제 시간 및 긴 문장의 끝까지 읽기 개선 정도는 유료 합성을 하지 않은 현재 시점에서 실청취 검증 전 상태.

## 안전 및 검증

- 추가 API 합성, GCS 업로드, Cloud Run 재배포, 운영 main 반영은 승인 전 금지.

- 무료 전체 회귀 테스트: `python3 -m unittest discover -s study-note/tts -p "test_*.py" -q`
- 최종 소량 재합성은 별도 승인하에 정확한 토픽/문장/호출수/글자수 산출 후 진행.
