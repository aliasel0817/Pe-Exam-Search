## 기능 동작

- **연속 읽기 모드에서만**, 현재 필터 목록 가운데 선택된 읽기 항목의
  비어 있지 않은 원문에 해당하는 MP3 항목이 매니페스트에 **없을 때**,
  해당 토픽을 통째로 건너뛴다.
- 사용자에게 재생 종료 후 `재생 n개 · MP3 미생성 m개 건너뜀` 알림.
- 모든 토픽이 미생성이면 재생/토픽 이동/서명 URL 다운로드 없이 중단.
- 건너뛴 토픽은 화면 이동하지 않으며, 준비된 토픽 사이에서만 회상 간격 적용.
- 전체 약 4,000개가 미생성이어도 이미 조회한 매니페스트만 사용.
  조회 횟수 폭증, 자동 생성, 읽기 요청 반복 없음.
- **보안/콘텐츠 오류는 건너뛰지 않는다**:
  MP3 매니페스트에 키가 존재하지만 SHA-256 불일치,
  객체 경로·분할 순서 위반, Cloud Run 인증 오류, 네트워크·재생 오류 발생 시 중단.
- "현재 토픽만" 모드의 누락 MP3 검사는 기존대로 오류 안내 후 중단.
- 정지 시 `AbortController`로 진행 중인 GCS 서명 URL 요청 및
  실제 MP3 GET을 가능한 즉시 취소. 중지 후 후속 다운로드·재생 금지.
- 매니페스트 조회와 기존 CacheStorage 항목 보존은 변경하지 않음.
- 중지·토픽 이동·필터 변경·장시간 재생 정책은 무한 반복하지 않고 유한하게 종료.
- iPhone 잠금 화면/백그라운드 오디오의 장시간 유지 여부는 브라우저 정책에
  좌우되어 별도의 3기기 실기기 검증이 남음.
