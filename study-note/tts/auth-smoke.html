학습노트 TTS — Google 로그인 실검증

이 페이지는 개발용 테스트 화면입니다. 현재 운영 학습노트와 PDF·필기·Sheets 데이터는 변경하지 않습니다.

시험하는 내용: Google 로그인으로 발급받은 ID 토큰이 현재 Cloud Run 서버의 인증·허용 계정 검사를 통과하는지 확인합니다.

하지 않는 내용: 음성 생성, MP3 업로드·다운로드, 새 Cloud Run 배포, 토큰 저장 또는 화면 표시.

페이지를 열면 로그인 준비 상태를 확인합니다.

계정이 허용되지 않으면 HTTP 403이 나타날 수 있습니다. 오디오 목록이 아직 없으면 인증 성공 후 HTTP 503이 나타날 수 있습니다. 결과 화면만 공유하고 개발자 도구의 인증 토큰이나 네트워크 헤더는 공유하지 마세요.
