- 비공개 GCS의 MP3 **12개**를 독립 시험 페이지에서 모두 정상 재생했다고 사용자가 확인.

- 기존 본문 MP3 7개, 토픽명 MP3 5개, ZIP 및 GCS 객체를 보존한다.

## 개발 브랜치의 실제 학습노트 PWA 연결 변경
1. `study-note/tts/cloud-config.json`의 개발 브랜치 전용 모드를 `gcs-private`로 설정.
   이미 실사용이 검증된 `study-tts-audio-gateway-hgli3gua6q-uc.a.run.app`과
   `study-note-tts-audio-558407087449` 버킷을 연결.
   **운영 main에는 해당 설정·TTS 재생기가 게시되지 않았다.**
2. `study-note/tts/natural-tts.js`
   - 토픽명 + 선택한 본문 6개 읽기 순서 및 데이터 SHA-256 확인 유지.
   - 토픽명 단독 듣기 지원 (본문 6개 전체 해제).
   - 선택한 토픽의 모든 비어 있지 않은 읽기 항목을 **재생/토픽 이동 전에** 검사.
     미생성 MP3/수정 원문/경로 이상이면 자동 생성하지 않고 중단.
   - GCS 서명 URL의 버킷, 정확한 객체 경로, HTTPS, 서명, 1~300초 만료 제한 확인.
   - 다운로드/재생은 사용자 클릭 후에만 이루어짐. 자동 합성·업로드·서버 쓰기 없음.
   - 선택 가능 음성은 청취 확정된 `ko-KR-Chirp3-HD-Aoede`뿐.
3. `study-note/study-note.html`
   - 현재 소수의 토픽/필드만 MP3 생성된 상태임을 안내.
   - 스피커/설정/6개 체크박스/토픽 이동 브리지 유지.
   - 미생성 Kore/Charon 선택 금지 표시.
   - 개발용 시험은 `현재 토픽만` 및 `현재 토픽 MP3 준비 확인` 사용 권장.

## 2026-10-10 후속: 듣기 버튼 공간 절약 UI 개발 완료 (dev 전용)
- 사용자 제안 채택: 듣기 버튼을 짧게 눌러 재생/정지, 길게(550ms) 눌러 독립 옵션 팝업.
  필기도구의 `bindAnnotationLongPressButton()`과 동일한 길게 누르기 시간과 12px 움직임 허용값 사용.
- 옵션 전용 톱니(⚙) 버튼은 제거. 옵션 팝업은 실제 `position:fixed`를 이용하며
  `document.body`에 이동하여 스크롤 카드에 잘리는 것을 방지함.
  iOS visualViewport 크기/이동 대응, 높이 제한 및 내부 스크롤.
- 짧은 재생 버튼 왼쪽 아닌 **바로 옆**에 `↻ 1회 / ↻ 2회` 직접 전환 버튼 설치.
  기존 '토픽 반복 1/2회' 옵션은 팝업에서 제거. 1/2회는 토픽마다 읽는 횟수이며
  무한 반복이 아님. '현재 토픽만 / 검색 목록 연속 읽기'는 여전히 팝업에서 선택.
- 오작동 방지: 길게 누른 후 발생하는 합성 클릭 차단, 12px 이상 드래그 차단,
  포인터 취소/이탈 시 타이머 취소, 우클릭 팝업, Alt+↓ 팝업, Esc/닫기/외부 클릭 닫기.
  키보드 Enter/Space는 보통 클릭과 동일한 재생/정지 동작.
  모바일 OS의 기본 터치 콜아웃을 차단해 길게 누르기 지원.
- 옵션 팝업에는 재생 범위·속도·회상 시간·선택할 읽기 항목 6개,
  Google 로그인/MP3 상태 확인 등이 유지됨. 읽기 항목 전부 해제 시 토픽명 단독 청취 가능.
- 반복 횟수는 기존 `peStudyNote.aiTts.options.v1` 로컬 사용자 설정에 보관.
  재생 도중 변경 시 현재 음성은 안전 중지하고 상태 문구에 명시.
- Google Sheets/Apps Script/PDF/필기/검색 및 기존 Cloud Run/GCS에는 쓰기 없음.
- 기존 운영 `main`의 학습노트 화면에는 **아직 미반영**.
- Node 가짜 DOM/클라우드 전체 회귀 7개 파일 **88/88 통과** (이후 마지막 문구 변경 재검증 필요).
