## 1. T0255 — 동일 명칭 아래 개념 범위가 다른 문제

### 보존형 선택지

1. **안 A(학습 교재 우선)**: T0255를 연결 교재의 과정 중심 사고로 정의하고 네 단계·Focused Improvement를 Y에 포함. 기존의 고객가치/업무 프로세스 관리 설명은 별도 기존 토픽 또는 신규 토픽에 **손실 없이 보존**할 수 있는지 조사 후에만 반영.
2. **안 B(기존 LIVE 의미 우선)**: T0255의 고객가치 기반 설명 유지, **연결 교재가 다른 Process Thinking 용례**임을 분리 표기할 방안 마련. PDF가 현재 LIVE에 대한 직접 근거라는 주장은 제거하거나 별도 자료 추가 후 판단.
3. 기존 내용 전면 치환, 토픽 삭제·병합, Q 연결 변경을 **현재 단계에서 모두 보류**.

교재 우선안을 선택한다면 가능한 **미승인 예시 문구**:
- J(50자 이하 시안): **현재의 준비·실행·성찰 과정을 중시하며 원하는 성과를 개선하는 사고방식**

## 2. T0355/T0356 — What-if와 Goal Seeking의 범주 관계

### 원천 vs LIVE

- `MG:54` 서브노트의 행 제목은 **목표값 찾기(what-if 분석)**이지만 본문 설명은 **입력 셀 값 변동 → 수식 결과의 영향 확인**(정방향)임. **원본 내 제목/설명 불일치 가능성도 별도로 존재**.
- 같은 페이지의 Goal-Seeking Analysis 행은 **원하는 결과를 정한 뒤 입력변수를 지속 변경하여 찾는 역방향 탐색**임. Sensitivity Analysis(입력 변화에 대한 영향도)와 Optimization Analysis(제약 범위 내 최적값)도 개별 행으로 제시.
- LIVE T0355(row 280): I는 목표값 찾기(what-if 분석), J/X/Z의 **역산·목표결과 사전지정** 내용은 Goal Seeking에 가까움. K/Y도 문장 파편화.
- LIVE T0356(row 281): I는 목표탐색 분석(Goal-Seeking Analysis), J/X는 **목표결과→입력변수 역산**으로 원천 Goal Seeking과 정합. T0358(row 282)과도 구분 필요.
- 참고로 **Microsoft Excel 공식 설명**에서 What-if Analysis는 Scenarios, Data Tables, **Goal Seek**를 포함하는 *상위 분석범주*이고, Goal Seek는 목표 수식 결과를 만드는 **단일 입력변수**를 계산하는 별도 도구. 따라서 두 용어는 상호배타적 상하 병렬 분류가 아니라 **상위 범주와 특수 기법의 관계**: https://support.microsoft.com/ko-kr/excel/introduction-to-what-if-analysis

### 제안 (LIVE 미반영)

- **우선안:** T0355 I를 **가정분석(What-if Analysis)**으로 명확히 하고, J/Y/X/Z를 *입력 변화→결과 비교*에 초점을 맞춤. T0356은 **목표탐색 분석(Goal-Seeking Analysis)**으로 유지해 *정한 출력목표→입력값 역산*을 별도 보존. T0358 민감도 분석의 영향도 측정도 보존.
- 제목 I 변경은 검색·암기 이력과 사용자의 기존 표제어에 영향을 주므로 **사용자 명시 승인 전 금지**. 원본의 '목표값 찾기' 제목도 과거자료 근거로 따로 남길 것.
- T0355 J(50자 이하 **제안 시안**): **입력값을 바꿔 수식 결과에 미치는 영향을 확인하는 가정분석 기법**
- T0355 Y(설명형 **제안 시안**): 입력변수(Input Variable, 입력변수)(분석할 가정과 변경할 값을 설정) · 관계수식(Formula, 관계수식)(입력과 출력 사이 계산규칙 정의) · 결과변수(Output Variable, 결과변수)(변경된 입력에 따른 계산결과 확인) · 가정 시나리오(Scenario, 가정 시나리오)(입력값 집합별 가능한 결과 비교) · 결과해석(Interpretation, 결과해석)(기준과 변화 결과를 비교해 의사결정 지원)
- 시안의 `가정 시나리오`는 원본 MG:54 해당 행만의 단어가 아니라 Microsoft What-if 일반 기능을 참고한 **확장 제안**임. 반드시 원천 단어(`입력변수·결과변수·함수/수식·값 변경·결과 영향`)가 우선. 공식 기능별 시나리오·데이터표·목표값찾기의 관계를 보존해야 함.
- T0356의 현재 `목표값·입력변수·반복계산·역산` 및 금융·가격·생산량 활용 예시는 **T0355를 고치더라도 삭제하면 안 됨**.
- 검수 차원의 비교 도식: **T0355(정방향: 입력 가정 → 결과 변화) / T0356(역방향: 결과목표 → 입력값 계산) / T0358(민감도: 입력 변화량 ↔ 출력 영향도)**.

## 3. T0310 — 페이지 연결 범위 적합성 검토

- LIVE T0310(row 32) I: 경영전략 프레임워크; J/K/X/Y는 전략환경·내부역량·전략대안·실행계획·피드백을 설명. P = **MG:5**.
- 교재/서브노트 파일테이블에 해당 토큰의 서브노트 **MG_0005.pdf**는 실제로 **전사 통합 플랫폼 아키텍처 도식 2개**를 포함. ERP/SCM/BI/DW/KMS/BPM/EAI/e-CRM/전자상거래/보안 계층과 **'지능형 디지털 엔터프라이즈 통합 플랫폼 아키텍처'**의 AI/클라우드 재구성 도식임. **전략계획 단계/평가-환류 프레임워크의 직접 원천으로 보기 어려움**.
- LIVE에서 **T0402 지능형 디지털 엔터프라이즈 통합 플랫폼 아키텍처**도 **P:MG:5(서브노트)**를 직접 연결하며, 이는 T0310 P:MG:5와 동일한 Drive 서브노트 파일 ID(1Oxdv336gynWYJnNGqNGftcKzyckaaU91)의 플랫폼 도식과 일치. 한편 **T0210 ITO**의 **Q:MG:5는 '교재'**이며 Drive 파일 ID(1K9oCe3RiWr6_gvdxt_jAAXxawogIekR_)가 **서브노트와 다른 별도 PDF**임. 페이지토큰 문자열이 같아도 출처유형이 다르면 파일이 달라지므로, T0210을 같은 이미지 증거로 인용하는 오류 금지. 여러 토픽이 동일 서브노트 페이지를 공용으로 사용할 수 있으므로 자동 재연결·삭제 금지.

- 현 단계 판정: **원본 자료-토픽 주제 초점 불일치 증거 확보 / 잘못된 페이지 연결 확정은 보류**. 현재 P 연결은 유지.
