## 추가 140개에 대한 독립 1차 검수
- 표제어/설명문·토픽명·키워드(K)·특징(X)·해당 기술요소 주변 원문을 대조하는 두 방법을 조합.
- **문맥우선 60개**: 수치·평가, 인증·인가, 송수신·복구, 정책·규격, 구현 문맥 등을 포착한 정규식으로 후보를 선별하고 도메인별 균등간격 표본을 추출.
  - MG 8, SW 14, SV 10, DB 6, NW 6, AI 5, SE 5, ST 5, AL 1 = **60**.
- **나머지에서 별도로 계층표본 80개**: MG 12, SW 25, SV 16, DB 7, NW 7, AI 6, SE 4, ST 2, AL 1 = **80**. 앞서 선택한 60개 요소와 **중복 없음**.
- 표본은 재현가능한 입력행 순서·도메인별 균등간격 위치 `floor((j+0.5)×N/q)`에 따라 선택. 무작위·대표통계 추정이 아니며 자동으로 나머지 전체의 품질을 보증하지 않음.
- **추가 140개 1차 판정**:
  - **137개**: 짧은 표/단계·역할 설명으로 현재 문맥에서 유지 가능.
  - **1개**: 공식 표준과 비교 시 설명 범위 정밀도 후속검토 필요(`T3144`).
  - **2개**: 화살표 기반 절차/체계형 원문(`T0070`, `T0172`)은 마지막 괄호를 독립 설명으로 잘못 단정하면 안 되므로 **형식상 별도 유지**. 원문 형식 이상/오류로 확정한 건이 아님.
- **참고:** 이 단계는 140개만 토픽별 검토한 것이며, 1,640개 전체에 대하여 위험 단어·형식 탐색을 했다는 뜻과 개별 의미검수를 구분.

## 내용·표준 교차확인 상세
| 통합ID | 항목 | 분류 | 근거 |
| --- | --- | --- | --- |
| **T3144** | SE / Delta CRL | **정밀도 확인 후보** | RFC 5280에 따르면 델타 CRL은 폐지 추가뿐 아니라 상태변경, 보류 해제·`removeFromCRL`도 반영. '변경된 폐지항목만 추가 제공'은 신규 폐지항목 추가로만 오해될 수 있음 |
| T2581 | NW / CRC Remainder Check | **유지 가능** | 해당 원본에는 뒤이어 Zero Syndrome의 0 판정과 Error Indication의 비영(非零) 판정 단계가 **별도로 이미 존재**. 짧다고 내용을 중복 보강할 필요 없음 |
| T2086 | ST / t검정 Standard Error | **유지 가능** | 토픽 설명은 단일/독립/대응표본을 모두 다루며 Mean Difference에 '평균 또는 평균차'가 별도 명시됨. 요약 자체를 오류로 확정할 사유는 아직 없음 |
| T2091 | ST / p Value | **유지 가능** | 같은 구성에 Sampling Distribution의 귀무가설 하 분포와 Decision Rule을 명확히 연결. p값 요약 단독문장은 짧지만 전체 맥락에 조건이 있음 |
| T0070 | MG / BSC 수립체계 | **원본 절차 형식 유지** | `Vision → Strategy → ... → Initiative(...)` 형태는 마지막 괄호만 떼면 전체 원문 의미를 잃는 순차 도식. 부호·순서 유지 |
| T0172 | MG / ISO/IEC 20000 구성도 | **원본 절차 형식 유지** | `Organization Context → ... → Improvement(...)` 형태의 단계체계. 괄호/화살표 원문 무변경 |
