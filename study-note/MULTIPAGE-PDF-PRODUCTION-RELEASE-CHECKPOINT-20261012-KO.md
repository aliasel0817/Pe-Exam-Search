## 2. 배포된 기능과 보호 대상
- 서브노트·교재 새 원본/누락/보강/개정의 **다중 페이지 PDF 자동 분할 및 페이지별 업로드 준비**.
- 기존 원본 파일의 다중 교체는 별도 `-R#` 개정판으로 등록해 기존 원본 PDF 자체를 덮어쓰지 않음. 기존 1페이지 직접 교체 경로는 유지.
- 개정판은 연속 페이지를 먼저 저장하고 **개정 첫 페이지를 마지막에 발행**하여 미완성 개정판의 조기 활성화 위험을 줄임.
- 새 페이지키·페이지번호 충돌 차단, 잘못된 보강/개정 기준 키 차단, 등록계획 비동기 상태 변경 무효화, 중간 실패 후 같은 관리창에서 미업로드 페이지 재시도 지원.
- 각 문서의 **첫 페이지키만 토픽에 직접 연결**, 원본 **앞/뒤 1페이지** 버튼으로 이어서 열람.
- 제한: 입력 PDF 64 MB 이하, 최대 200페이지, 분할 후 1페이지 PDF당 8 MB 이하.
- 운영 Google Sheets 기존 학습 원문, 기존 PDF·페이지키·PDF 관계, 기존 TTS/MP3/GCS 및 Apps Script는 이 작업에서 **수정하지 않음**.
- 콘텐츠 완전성 감사 PR #8은 별도 **Open/Draft** 상태로 유지. 통합 콘텐츠 검수는 중단 지점에서 재개.

## 4. 사용자의 최초 확인 권장 경로
1. 운영 주소 `https://aliasel0817.github.io/Pe-Exam-Search/study-note/study-note.html`를 온라인에서 열고 **설정 → 앱 버전**이 `4.6.11-all-material-multipage-rc1`인지 확인.
2. 설정의 **📖 사용자 매뉴얼**로 사용법 확인.
3. **기존 데이터와 분리된 검증용 토픽**에서 2페이지 샘플 교재 PDF 신규등록 → 저장 → 첫 페이지 표시 → **원본 뒤 1페이지** → 두 번째 페이지 → 이전 복귀를 확인.
4. 동일하게 서브노트, 보강, 개정 경로를 소량 시험. 기존 원본과 페이지키를 덮어쓰거나 삭제하지 않음.
5. 실패 시 기존 업로드 성공 여부를 확인하고 **관리창을 유지한 채 저장 재시도**. 배치 전체 원자적 롤백은 제공되지 않음.
