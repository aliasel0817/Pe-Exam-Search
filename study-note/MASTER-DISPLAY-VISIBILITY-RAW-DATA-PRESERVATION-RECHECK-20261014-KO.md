# 학습노트 가시성 개선 — 원본 MASTER 무변경 원칙 및 과거 셀 변경·의미 손실 재확인 (2026-10-14)

> **최우선 목적 재확정:** 운영 Google Sheets MASTER 원문을 바꾸지 않고 학습노트 PWA의 **특징(X), 기술요소·구성요소(Y)**를 개별 항목의 독립 줄(`가. 요소명 : 설명`, `나. 요소명 : 설명` 또는 번호형)로 렌더링하여 가시성을 개선. 영어는 기술적 의미를 지키면서 한글 중심으로 **표시만** 변환. 데이터보존 검수와 화면 QA를 우선. **과거 문구 변경의 복구/정정은 별도의 승인 경로**.
>
> **이 문서는 발견사항의 읽기 전용 체크포인트**. 운영 LIVE Sheet, PDF/페이지 연결, PWA/Apps Script/TTS, `main` 무변경. PR #8 Draft/Open/미병합. 공개 GitHub에는 전체 원문 셀을 복제하지 않고 식별자·차이요지만 기록.

## 1. 원문 변화와 화면 표시 변환의 엄격한 구분

- '표시 개선은 MASTER 원문 무변경'은 **앞으로 지켜야 할 설계·작업 원칙**이지, '과거에 MASTER 원문을 실제로 한 번도 변경하지 않았다'는 역사적 사실이 아님.
- 2026-10-06 `topic_study_data_BACKUP_MASTER_CONTENT_ENRICHMENT_FINAL_APPLIED_20261006` vs 2026-10-11 `topic_study_data의 사본`: 공통 **3,855 통합ID**를 ID 기준으로 대조.
  - I(제목) 0 변경, J(개념) 0 변경, K(키워드) 0 변경.
  - W(등장배경) **3,266 변경 / 1건 짧아짐**.
  - X(특징) **3,674 변경 / 2건 짧아짐**.
  - Y(기술요소) **3,265 변경 / 0건 짧아짐**.
  - W/X/Y 전부 이전 비공란이 신규 공란이 된 사례는 없음. 그러나 문자열 길이 증가는 **일부 설명구절 삭제가 없음을 입증하지 못함**.
  - 10/11에 처음 등장한 통합ID는 T4036, T4037, T0000. 기존 토픽 통합ID 삭제 0.
- 해당 역사적 문자열 변경이 정확히 어느 사람이 어떤 배포·가시성 단계에서 발생했는지는 **수정행위 로그 없이 단정할 수 없음**. 다만 과거 실제 원본 셀에 내용 변화가 있었던 사실은 확인.

## 2. 내용이 실제로 빠진 확정 사례 3건 — '단순 번역/확장'이 아님

## 3. 2026-10-11 사본 ↔ 2026-10-14 LIVE 재비교

- 10/11 사본 **3,858토픽 (Y 3,799 / N 59)** vs LIVE **3,859토픽 (Y 3,800 / N 59)**, 통합ID 공통 **3,858**, 삭제/중복 **0**. 추가 ID **T4038 (양자오류정정, QEC)**.
- 공통 ID의 핵심 필드 **J/W/X/Y/Z 전부 문자열 변경 0**. 제목 I 한 건 수정(T4036 끝의 불필요한 `기술욕키워` 삭제), K 한 건 수정(T3385 `QEC(양자오류정정)` 추가), Q 한 건 변경(T4036에 `SE-2:1` 추가).
- 위 신규 토픽/수정의 **수정자·발생원인 미확인**. 가시성 작업이나 현 감사 작업에 기인한다고 단정하지 않음.
- T4038은 W/K 및 일부 보강열 공란과 자체 문구 구조가 기존 형식과 다름. 새 토픽을 전체 학습대상 표본에 포함하는 다음 구조검사가 필요. 기존 3,799 기준은 시점 구분해서 사용.

## 4. 앞으로의 최상위 회귀검수 조건

1. **표시 로직만 변경:** UI 파서는 원문을 메모리에서만 해석·렌더링하고 원본 Google Sheets에 쓰기·정규화 저장·자동수정하지 않음.
2. **항목 보존:** ` · ` 구분자, 괄호 중첩, 필수 약어/명칭, 하나의 요소의 설명 속 괄호 등 구조 예외까지 인식. `가./나./다.` 또는 `1./2./3.` 개별 행으로 표시. 원문 순서/요소 수/전체 설명·하위단계/숫자/수식 보존을 검사.
3. **한글 우선은 화면 표현에 한정:** 영문-한글 대응의 정확성을 보장할 수 없으면 원래 기술명을 유지. RFC명, 표준번호, 알고리즘·메시지명은 무손실 유지.
4. **역사적 손실 복원은 별도 트랙:** 이번 T0493/X, T0466/W, T0521/X 3셀 복원 후보는 과거 비공개 백업과 LIVE의 차이를 대조해 기술적으로 적절한 최소 시안을 문서화하고 **사용자의 명시 승인 전 운영 LIVE 미수정**.
5. **두 작업의 완료율 분리:** PDF 원본 시각 1차 대조 61/3,799는 기존 시점의 이력이며, **화면 가시성 개선 진척으로 계산 금지**. 현재 새 1개가 추가된 LIVE는 3,800 학습대상으로 별도 업데이트.
6. **작업 재개 시 필수 확인:** GitHub `main`/PR #8, LIVE ID 수·공란·백업 변동 확인, 이 고정 목적을 최상단에 재확인. 기존 PDF 개발 인터럽트/TTS 중지 유지.
7. **UI 화면 개선 실측:** PC·태블릿·모바일 줄바꿈·행간·스크롤/레이아웃 및 요소/설명 매칭, 긴 괄호·비정형·절차도 케이스. 무손실 여부와 보기 좋은 정도를 분리해 보고.
8. **원본 삭제로 보이는 변경을 0건이라고 단정 금지**. 이미 위 3건이 확정되어 있음. 신규 편집자의 작업 귀속은 수정기록 확인 후 판정.
9. **Apps Script:** 변경/저장/함수실행/재배포 모두 불필요. 운영배포 없음.
