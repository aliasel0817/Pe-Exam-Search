## 2. X 특징 항목: 의미 근거가 확인된 한글 우선 표시

기존 Y 기술요소는 Phase 8부터 한글 우선 + 영문 병기 지원. 이번 단계에서는 **X 특징의 개별 줄에 원문 자체가 명시한 영어(한글) 쌍**이 포함되어 있을 때 다음 조건을 모두 만족해야 한글을 앞세움.

1. 해당 X 원문에 영문명과 한글명이 **직접 병기**되어 있을 것.
2. 기존에 검토된 정확한 `STUDY_TECHNICAL_GLOSSARY`의 영문/한글 쌍과 **문자열이 일치**할 것. 같은 영문의 다른 뜻 또는 번역 불명확 시 미전환.
3. 약어/표준번호/숫자/합성 기술고유명칭을 무리하게 뒤집지 않도록 영문 제목형 일반 어휘 패턴에 한정.
4. `Initial Data(데이터)`처럼 더 긴 영문 표현의 일부만 떼어 번역하지 않도록 선행 영문 어휘가 있으면 제외.
5. `textContent` 기반으로 `고객 (Customer)` 형태로 표시하되 **영어는 삭제하지 않음**. 항목 전체 원문은 DOM의 `data-study-original-item`에 변경 없이 보존. 번호/목록 개수/순서와 설명·수치·괄호는 그대로 유지.
6. 비정형·기존 번호/계층형·일반 해석이 필요한 표현은 원문을 그대로 유지. **이 검증은 자동번역 또는 원문 재작성 과정이 아님.**
