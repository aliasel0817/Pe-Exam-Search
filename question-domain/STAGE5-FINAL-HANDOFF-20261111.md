## 4. 최종 수치

- Sheet1: 헤더 포함 **20,798행 × 9열** (기존 7열 + H/I 두 열)
- Sheet2: **빈 시트 유지**

- H열 주도메인: **18,223건 입력, 2,574건 공란** (87.6% 입력률)
- I열 연관도메인: **2,468행 입력, 18,329행 공란** (11.9% 입력률)

- 복수 관련 도메인 구분자: ` | `; 주도메인과 연관도메인 코드 중복 없음

- **입력률은 정확도를 뜻하지 않음**. 자동 분류의 오분류 가능성 존재
