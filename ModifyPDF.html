PDF 편집 가능한
사본 만들기

읽기 암호가 없어도 사용 가능합니다. PDF를 선택하고, 열기 암호가 있는 문서만 암호를 입력하세요. 문서 열기 암호와 PDF 편집 권한 제한이 없는 사본을 저장합니다.

파일 및 암호는 외부 서버에 업로드하지 않습니다.
PDF는 기본적으로 브라우저에서 처리합니다. HTML만 실행하는 경우 PDF 처리 라이브러리를 불러오기 위한 인터넷 연결이 필요합니다. 보조 실행 방식에서는 PC 내부의 로컬 서버에서 처리합니다.

2

문서 열기 암호 (선택 사항)

읽기 암호가 없는 PDF: 이 칸을 비운 상태로 진행하세요.
읽기 암호가 있는 PDF: 알고 있는 열기 암호만 입력하세요. 편집 암호는 필요하지 않습니다.
✓ 편집용 PDF 생성이 완료되었습니다.
  • 저장된 PDF에는 열기 암호가 없습니다.
  • PDF 암호화에 따른 편집 권한 제한도 없습니다.
  • 원본 PDF는 변경하지 않았습니다.

처음 사용하시나요?

  1. PDF 파일 찾아보기로 원본을 선택합니다.
  2. 원본이 읽기 암호를 요구하지 않으면 암호 칸을 비워둡니다. 열 때 암호를 요구하면 알고 있는 암호를 입력합니다.
  3. 편집 가능한 사본 만들기를 누릅니다.
  4. 새 PDF 다운로드를 눌러 편집용 파일을 저장합니다.

새 파일은 읽기 암호 없이 열리며, PDF 암호화로 인한 편집 권한 제한이 제거됩니다. 원래 암호가 없는 문서는 별도 사본을 저장합니다. 디지털 서명·일부 양식·첨부 파일은 변경될 수 있고, 스캔 PDF가 자동으로 편집 가능한 글자로 변환되는 것은 아닙니다. 본인이 소유하거나 편집 권한이 있는 문서에 사용하세요.
